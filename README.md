# PocketDeck 口袋舰桥

PiDeck 桌面端的手机客户端。电脑上聊到一半的 AI 会话，手机上接着聊——同一个 Wi-Fi 下扫个码，打开就是上次的会话。

桌面端（上游）：[ayuayue/PiDeck](https://github.com/ayuayue/PiDeck)。
版本号跟桌面端的主版本对齐，`-n` 后面是这个主版本下推的第几版：比如 `v0.9.8-n1`，就是同步桌面端 `v0.9.8` 之后推的第一版，下一个补丁推 `v0.9.8-n2`。

## ✨ 核心亮点

- 📱 **扫码就进聊天** —— 电脑上打开配对二维码，手机一扫，进去就是上次聊的会话，不用翻列表找
- 💬 **流式照着网页做** —— 文本、思考、工具按到达顺序一段段冒出来，执行卡三级折叠，和桌面网页版看到的一致
- ✅ **审批在手机上点** —— 桌面端弹"继续吗"这类确认时，手机底部滑上来就能选，不用跑回电脑前
- 🐳 **pi / DSH 双后端** —— 同一个会话列表里两种后端混排，DSH 还有权限预设和工具面板（目标 / 子代理 / 技能 / 插件）
- 🔍 **会话内搜索** —— 服务端索引命中，点一条直接跳到那条消息
- 📊 **用量看得见** —— 顶栏上下文圆环，点开是窗口占用 + 供应商额度（余额 / 额度窗口 / 滚动周期）
- 🗂️ **会话随身带着走** —— 重命名、复制、导出 HTML、删除，聊天页溢出菜单里还能复制成 Markdown、拉一次最新消息
- 🛠️ **顺手看一眼代码** —— Git 改了啥、项目里有哪些文件，聊天页点一下就能看，Markdown 直接渲染

## 🧩 功能总览

### 配对与连接

| 功能 | 说明 |
|---|---|
| **扫码配对** | CameraX + MLKit，扫码拿地址（缺端口默认 8765），相机权限没给会引导去设置 |
| **手动输地址** | 相机不好使（模拟器、扫码失败）可以直接敲 `http://<电脑IP>:8765` |
| **配对持久化** | 地址存在 DataStore，下次打开直接进上次的会话 |
| **断线重连** | 顶栏状态跟着 runtime/streaming 走，服务端在跑但本地没订阅时自动跟随 |

### 聊天

| 功能 | 说明 |
|---|---|
| **历史分页** | 上滑加载更多，一次 30 条，到顶为止；拿不到历史会显示行内错误，输入框照常能打字 |
| **流式回复** | 发一句回一句，思考/工具按到达顺序分段，点发送键可中断（先弹确认） |
| **自动跟随** | 默认跟着新内容走，手滑离底部才暂停，回到底部自动恢复；箭头收在输入框里不悬浮 |
| **发图** | 相册或拍照，最多 4 张，大图压到 1600 长边再传，走 `parts` 的 `type=file` 节点 |
| **模型和档位** | 输入框展开后第二行直接换；跑着的时候换立即生效，没跑的时候换下次生效 |
| **计划模式** | 输入框工具栏一键开关，Agent 先出计划、确认了再动手 |
| **提示词库** | 分类 + 搜索（250ms 防抖），点条目插进正文 |
| **Markdown 渲染** | 表格、代码块、引用、行内样式，网页能显示的这里基本都能 |
| **技能与扩展** | 溢出菜单里看当前部署装了哪些技能/扩展，能启停 |

### 会话与搜索

| 功能 | 说明 |
|---|---|
| **分组抽屉** | 按项目分组、默认折叠、展开状态记住；Chat 置顶，带搜索和新建 |
| **会话内搜索** | 溢出菜单里搜会话消息，走服务端索引，命中点一下跳到那条消息；索引不可用回退本地搜索 |
| **重命名 / 删除** | 会话上直接操作，不用开电脑 |
| **复制** | 想留个快照就复制一份，原件继续聊 |
| **导出 HTML** | 导出成 HTML 分享，或者从聊天页复制成 Markdown 贴到别处 |
| **刷新消息** | 服务端那边有变化，拉一次最新的，不用退出去重进 |
| **项目移除** | 抽屉里项目行长按，只删 catalog 记录，**不动磁盘上的文件** |

### 审批与监控

| 功能 | 说明 |
|---|---|
| **审批卡** | 底部滑上来；单选、多选、填字，点选项只是选中，点"提交"才算数；滑掉不提交 |
| **文件修改** | Agent 改了哪些文件、改了多少行，常驻一条 |
| **子代理** | 起了几个、跑完没、报错没，点开看结果 |
| **待办** | Agent 的 todo 还剩几条，完成度一眼看到 |

上面三条 5 秒刷一次，刷失败了保留上次的内容，不闪白屏。

### 工作区

| 功能 | 说明 |
|---|---|
| **Git** | 当前分支、改了哪些文件、diff、提交历史 |
| **文件** | 项目文件浏览，点开预览，Markdown 渲染、代码带行号 |

工作区是底部弹出的面板，不是全屏页面——背后聊天还能看见。

### 外观

## 🐳 DSH 后端

桌面端除了 pi 还融合了 **DSH（DeepSeek Harness）**，手机端把这些能力也接了过来：

- **后端混排** —— 会话列表里 pi / DSH 会话一起排，靠 `backend` 字段区分，不额外建概念
- **权限预设** —— 顶栏盾牌图标，`Read Only` / `Workspace Write` / `Full access` 三档；有 runtime 时立即下发，没 runtime 就写进会话记录、下次运行生效；切到完全访问会先弹二次确认
- **工具面板** —— 一个 sheet 四个 tab：目标（阶段 / 轮次）、子代理（点开看历史）、技能（可调用的 `/name`）、插件（内置 / 动态，可启停装）
- **用量** —— 上下文 sheet 里的供应商额度块，DSH 走 `?backend=dsh`

空数组就是这套部署没开 DSH runtime，界面照实显示"没有…"，不假装有。

## 🏗️ 工作原理

```txt
手机 PocketDeck                        电脑 PiDeck 桌面端
┌────────────────┐   扫码拿地址    ┌────────────────────────┐
│ 扫码配对        │ ────────────── │ 配对二维码              │
├────────────────┤                ├────────────────────────┤
│ 聊天页          │  POST /api/chat（SSE 流式）              │
│ 抽屉 / 监控条   │ ────────────── │ Web 服务（如 :8765）     │
│ 工作区          │  GET /api/events（状态推送，断了退 5s）  │
│ 审批卡          │  GET /api/state（5s 兜底轮询）           │
└────────────────┘                └────────────────────────┘
```

说白了：电脑上的 PiDeck 起个局域网 Web 服务，手机就是个原生 UI 的壳。
发消息走 `POST /api/chat` 拿 SSE 流，一段段渲染；状态变化靠 `/api/events` 推，断了才退回轮询。
接口细节在 [`docs/api-contract.md`](docs/api-contract.md)，改接口先改它。

## 📦 下载安装

1. 电脑和手机连同一个 Wi-Fi，电脑上打开 PiDeck 的配对二维码（桌面端和手机端的主版本号对上，比如桌面 `v0.9.8` 配手机 `v0.9.8-n1`）
2. 去本仓库右侧 [Releases](../../releases) 下载最新 APK 装到手机上
3. 打开 APP 扫码，进去就是聊天

装不上的时候看一眼：之前装过别人打的包（签名不一样）会提示冲突，卸载重装就行，自己聊天记录都在电脑上，不丢。

## 🧰 快速开始（从源码运行）

要 Android Studio（或命令行 `gradle`）+ Android SDK，主线是 `android-native/`（Kotlin + Jetpack Compose）。

```bash
cd android-native
./gradlew :app:assembleDebug
```

跑起来后同样扫码配对。自己打 release 包：

```bash
cd android-native
./gradlew :app:assembleRelease
```

包在 `android-native/app/build/outputs/apk/release/app-release.apk`。
想要正式签名就把 `android/key.properties.example` 复制成 `android/key.properties` 填好；
不填也能打，就是 debug 签名，和正式包互相覆盖不了。

## ❓ 常见问题 FAQ

**扫码后连不上？**
先看手机和电脑是不是同一个 Wi-Fi，再看地址对不对（一般是 `http://<电脑IP>:8765`）。
电脑浏览器打开 `http://<电脑IP>:8765/api/health`，能看到 `{ok:true}` 说明服务是好的，
那就是手机网络或防火墙的问题。

**扫不出码？**
先确认相机权限给没给（没给的话扫码页会显示去设置）。MIUI 之类默认拒相机又不弹窗的机型，
手动点"输入地址"填一次也能用。

**历史刷不出来，显示 unavailable？**
那是服务端说这段历史现在拿不到，点重试就行。输入框里的字不会丢，读历史和发消息是两条道。

**发出去半天没反应？**
先看顶栏是不是显示 running。小概率是上一轮没断干净，回退重进一次会话就好；
正常重发不用重打字，长按原来的消息点重发就行。

**桌面端弹了确认框，手机上没看到？**
审批卡只显示当前会话的，3 秒刷一次。先确认你打开的是同一个会话，再等一两秒。

**切到后台回来卡住了？**
弱网下请求最多卡 10～15 秒自己超时，不会一直转圈。真卡死了杀掉重进。

> 注意：草稿是**内存态**，按会话隔离、切会话不丢，但进程被系统杀掉就没了。重要的内容先发出去。

**搜索搜不到老消息？**
会话内搜索走服务端索引，索引没建好时会提示"索引不可用"并自动回退到本地已加载的部分。
本地只搜得到已经加载进来的消息，想搜全量就等服务端索引。

**DSH 会话的权限菜单在哪？**
只在 DSH 会话出现，是顶栏的盾牌图标。pi 会话没有这个概念，所以不显示。

**图片发不出去？**
一次最多 4 张，单张太大 APP 会自动压缩后再传，实在太大就分两次发。

**工作区按钮不见了？**
多项目的时候，当前会话匹配不上任何项目会隐藏入口。回抽屉确认下会话所属的项目在不在。

## 🧑‍💻 开发指南

项目结构：

```txt
android-native/         # 主线：Kotlin + Compose，独立 Gradle 根
├─ app/src/main/…/pideck/
│  ├─ core/             # 扫码解析 + 配对存储 + REST/SSE 网络层 + 数据模型
│  └─ ui/               # 聊天 / 抽屉 / 工作区 / 配对 / 主题
├─ app/src/test/        # 单测（74 个）
docs/api-contract.md    # 接口契约，唯一真相源
```

动手前先看 [`AGENTS.md`](AGENTS.md)，实现铁律都在里面（很多是 bug 换来的）。
每次改完两条必须过：

```bash
./gradlew :app:testDebugUnitTest    # 全量通过（android-native/ 下跑）
./gradlew :app:assembleRelease      # release 包能打出
```

JDK 用 17 以上（本机默认指向 JDK8 的话先 `export JAVA_HOME=<jdk21 路径>`，否则会报
`Gradle requires JVM 17 or later`）。

## 🔒 安全与隐私

- **不联网外传**：手机只连你在局域网里指定的那台电脑，没有第三方服务、没有埋点统计
- **不发鉴权头**：局域网部署本身不校验 token，所以 APP 默认不带 `Authorization`；`token` 字段只是给公网部署预留的
- **会话数据在电脑上**：APP 只读接口，不落一份会话到手机；唯一的本地存储是配对地址和主题偏好
- **配对即信任**：拿到地址就能连，所以别把 PiDeck 的 Web 服务暴露到公网
